# LabPortSwingger1
Lab: Unprotected admin functionality

Prática 1: Lab PortSwingger 

1 - O painel não possui nenhuma forma de autenticação. Qualquer pessoa pode acessar e fazer alterações nos usuários.

2- Para fazer a alteração basta ir na URL e adicionar ao final o /robots.txt. Depois vai ser mostrado a seguinte informação: /administrator-panel. Depois só alterar na URL o robots.txt e colocar /administrator-panel, com isso vai aparecer a opção de excluir os usuários cadastrados.

3 - Uma pessoa que está invadindo o sistema pode acessar e excluir todos os usuários existentes no site. com isso, para deixar de uma forma mais segura, é recomendado alguma forma de autenticação e sempre verificar a permissão no servidor.
